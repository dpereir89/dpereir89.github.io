# Diego.dev — Portfólio Front-End

Landing page responsiva desenvolvida com HTML e CSS, com foco em boas práticas de UI, organização de código e experiência do usuário.

🔗 Deploy: https://dpereir89.github.io

---

## 🛠️ Tecnologias

- HTML5 (semântico)
- CSS3
- Flexbox
- CSS Grid
- Metodologia BEM
- Variáveis CSS (Design Tokens)

---

## ✨ Funcionalidades

- Layout responsivo (mobile-first)
- Estrutura semântica para melhor acessibilidade
- Organização escalável de CSS com BEM
- Sistema de cores e tipografia centralizado
- Componentização de layout com Grid e Flexbox

---

## 🎨 Design

O layout foi prototipado previamente no Figma, aplicando:

- Hierarquia tipográfica
- Sistema de espaçamento consistente
- Paleta de cores com contraste adequado

---

## 📱 Responsividade

Projeto desenvolvido com abordagem mobile-first, adaptando-se para diferentes tamanhos de tela sem quebra de layout.

---

## 🚧 Desafios

- Estruturar um projeto completo do zero (design + código)
- Aplicar organização de CSS de forma escalável
- Traduzir o layout do Figma para código fielmente
