# Diego.dev - Portfólio de Estudos (HTML/CSS)

Este é meu primeiro projeto front-end estruturado, desenvolvido após um mês de estudos focados em HTML e CSS. O objetivo principal foi aplicar na prática conceitos de UI Design e arquitetura de código que estudei recentemente.

## 🛠️ O que utilizei no projeto

### Design (Figma)
Antes de codar, utilizei meus conhecimentos de UI Design para criar o layout no Figma. Foquei em aplicar conceitos de:
- Hierarquia tipográfica e escolha de fontes.
- Paleta de cores e contraste.
- Sistema de espaçamento para guiar o olhar do usuário.

### Estrutura e Estilização (HTML/CSS)
- **HTML Semântico:** Uso correto de tags para melhor leitura do navegador.
- **Metodologia BEM:** Organizei minhas classes CSS no padrão `bloco__elemento--modificador` para evitar que o código ficasse confuso e difícil de manter.
- **CSS Grid & Flexbox:** - Usei **Flexbox** para componentes simples (menus, alinhamentos rápidos).
  - Usei **CSS Grid** (especialmente `grid-template-areas`) para organizar as seções mais complexas, como os cards de projetos.
- **Design Tokens:** Centralizei cores e tamanhos de fonte em variáveis CSS no topo do arquivo para facilitar alterações globais.

## 📱 Responsividade
O projeto foi desenvolvido com a mentalidade **Mobile-First**. Comecei a estrutura focada no celular e fui expandindo para telas maiores, garantindo que o layout não quebrasse em resoluções diferentes.

## 🚀 Desafios Superados
Neste primeiro mês de estudos, o maior desafio foi o ciclo completo de criação: desde a folha em branco no Figma — escolhendo tipografia, paleta de cores e definindo o conteúdo — até a escrita do código final. 

A curva de aprendizado foi intensa; absorver um volume tão grande de informações técnicas e aplicá-las em decisões reais de estrutura de projeto foi um processo exaustivo, porém recompensador. Ter o protótipo finalizado no Figma antes de codar foi a estratégia chave que permitiu uma implementação mais fluida, provando a importância do planejamento no desenvolvimento front-end.
